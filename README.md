# Psykologiatlas

Interaktiv studiesida i psykologi (Du och samhället, kap 10 och 11) med klickbara figurer, flashcards med repetition, quiz med förklaringar, studiekort och provfrågor med modellsvar.

Öppna sidan: se länken under **About** / GitHub Pages.

Kapitel: Identitet · Anknytning & lek · Grupper · Ledarskap · Normer & hjälp · Tre förklaringar · Studier · Alla begrepp

## Filer
- `index.html` – sidans skal
- `style.css` – utseende, ljust och mörkt tema
- `app.js` – gemensam motor: flikar, sök, flashcards, quiz, provfrågor, sparning
- `data.js` – allt innehåll. Ett nytt kapitel är bara ett nytt objekt i `chapters`.

Framsteg sparas i webbläsarens localStorage under nyckeln `psykatlas_v1`.
